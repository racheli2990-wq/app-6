# Knowledge Vault – Offline Encyclopedia

אפליקציית אנדרואיד בעברית לקריאת מאמרי ידע ללא חיבור לרשת.

## יכולות בגרסה הראשונה
- ממשק RTL בעברית
- חיפוש מקומי בכותרות, תקצירים ותוכן
- קטגוריות וערכים
- מועדפים והיסטוריית קריאה הנשמרים במכשיר
- מצב כהה ובהיר
- שיתוף והעתקת מאמרים
- ללא הרשאת INTERNET

## בנייה
נדרש JDK 17 ו-Android SDK. הריצו:
```bash
gradle assembleDebug
```
הקובץ יופיע ב-`app/build/outputs/apk/debug/app-debug.apk`.

כל push ל-main מפעיל GitHub Actions ומעלה artifact בשם `knowledge-vault-debug-apk`.

## הערה על המאגר
הגרסה הראשונית מכילה מאמרי דוגמה מקומיים. היא אינה כוללת את מלוא ויקיפדיה. ניתן להוסיף בהמשך חבילת ZIM/מאגר ידע גדול באמצעות قارئ ZIM מקומי, תוך שמירה על פעולה ללא אינטרנט.
